Version 1.0.27 added an audience variable to the token request of the generated client collections. A specification states no audience, so the generated files no longer carry one.

## Token request

The token request of an OAuth2 client credentials flow sends the grant type, the client id, the client secret and the scopes of the flow, and nothing else. The `audience` variable is gone from `variables.env` and from the Postman collection.
