An identity provider that issues tokens per API needs to be told which API the token is for. The generated client collections now carry that as a variable the reader fills in.

## Audience

A specification has no place to state an audience, so it is a variable. For an OAuth2 client credentials flow the token request now sends it beside the client id and secret.

| File | Variable | Where it is sent |
| --- | --- | --- |
| `hurl.zip` | `audience` in `variables.env` | the `audience` form field of the token request in `api.hurl` |
| `postman.json` | `audience` collection variable | an extra `audience` parameter in the body of the token request |
